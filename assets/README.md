# Source assets

Originals and superseded files kept for reference. **Nothing here is served by
the website.** It lives outside `public/` on purpose: everything in `public/`
uploads to the CDN on every deploy, and these were adding roughly 5MB for no
benefit.

| Folder                     | What it is                                                                                                                                |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `product-packshots-white/` | The original supplied packshots on white. Superseded by the background-removed versions in `public/products/cutout/`, kept as the masters |
| `superseded-cutouts/`      | Earlier cut-out attempts, no longer referenced                                                                                            |
| `efamy-logo-on-black.png`  | The supplied logo master. The light and dark versions the site uses are derived from it                                                   |

If a product photo ever needs redoing, start from `product-packshots-white/`.
